# RawThoughts

RawThoughts is the applied engineering, consulting and publishing practice of RawThoughts Enterprises Private Limited. We build tools for the work a team needs to carry forward: what it decided, what it wrote, and who can act on it next.

- [Pale](https://rawthoughts.in/pale/) keeps instructions, decisions and their reasons with agent work. [Licence](https://github.com/getHarshOnline/pale/blob/main/LICENSE) · [Notices](https://github.com/getHarshOnline/pale/blob/main/NOTICE)
- [Gazette](https://rawthoughts.in/gazette/) builds publications and documentation from the files their owners maintain. [Licence](https://github.com/getHarshOnline/gazette/blob/main/LICENSE) · [Notices](https://github.com/getHarshOnline/gazette/blob/main/NOTICE)
- [Scope](https://rawthoughts.in/scope/) explores how to give an agent the current context for a task. [Licence](https://github.com/getHarshOnline/scope/blob/main/LICENSE) · [Notices](https://github.com/getHarshOnline/scope/blob/main/NOTICE)
- [Weave](https://rawthoughts.in/weave/) describes a way to retain the relationships between records.

[Causality](https://causality.in/) and [Post-AGI Economics](https://post-agi-economics.org/) are research programmes. Start with the [working notebook](https://rawthoughts.in/), the [developer documentation](https://docs.rawthoughts.in/) or [services](https://rawthoughts.in/services/).
